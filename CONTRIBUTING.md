# Mitwirken an MetricCAD

Danke für Rückmeldungen, reproduzierbare Fehlerberichte und Verbesserungsvorschläge.

## Fehler melden

Bitte ein GitHub Issue mit folgenden Angaben erstellen:

- Betriebssystem, Browser und Python-Version;
- verwendeter Commit oder heruntergeladene Version;
- Schritte vom Programmstart bis zum Fehler;
- erwartetes und tatsächliches Verhalten;
- bei Geometriefehlern eine kleine, öffentlich teilbare Beispieldatei.

Keine vertraulichen Konstruktionsdaten, Zugangsdaten, vollständigen lokalen
Pfade oder Dateien aus `.metriccad` veröffentlichen. Für Sicherheitsprobleme
bitte den Weg in [SECURITY.md](SECURITY.md) verwenden.

## Änderungen am Code

Größere Änderungen vorab in einem Issue beschreiben. Pull Requests möglichst
auf ein Thema begrenzen und erläutern, welches Verhalten sich ändert und wie
es geprüft wurde. Die gemeinsamen Projekte, native Skizzen und die von Hand
bedienbare Oberfläche müssen bei MCP-Änderungen weiter funktionieren.

Installation und vorhandene Tests stehen in der [README](README.md).
Für Änderungen an CAD-Berechnungen oder dem MCP-Protokoll die passenden
Python-Integrationstests ausführen; bei Oberflächenänderungen zusätzlich
den betroffenen Ablauf im Browser prüfen.
